# Internal table UI primitives

Private `@bruno/shadcn` package containing the 18 primitives required by the imported table.
Source: shadcn-table commit `341c82dd2e5498a801e71fc4e1b62e5e0d57106d`,
original `packages/shadcn` directory. The original license and notices are retained.

Consumers use explicit package subpaths and `@bruno/shadcn/styles.css`.
This package remains an implementation dependency of `@bruno/table`.
